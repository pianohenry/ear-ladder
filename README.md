# Ear Ladder

Ear training for music students, in thirteen levels that climb from a single note in a key to altered thirteenth chords.

## Levels

| # | Group | Level | What you name |
|---|-------|-------|---------------|
| 1 | Single notes | Major scale degrees | Do to Do′, after a cadence |
| 2 | Single notes | Chromatic degrees | All twelve degrees, including Ra, Me, Fi, Le, Te |
| 3 | Intervals | First intervals | M2, M3, P4, P5, octave (ascending) |
| 4 | Intervals | All intervals up | m2 to octave, ascending |
| 5 | Intervals | All intervals down | m2 to octave, descending |
| 6 | Intervals | Harmonic intervals | m2 to octave, both notes together |
| 7 | Intervals | Compound intervals | m9 to M13 |
| 8 | Chords | Major or minor | Major and minor triads |
| 9 | Chords | All triads | Major, minor, diminished, augmented, sus2, sus4 |
| 10 | Chords | Triad inversions | Root, 6/3, 6/4 |
| 11 | Chords | Seventh chords | maj7, 7, m7, ø7, °7, m(maj7) |
| 12 | Chords | Seventh inversions | Root, 6/5, 4/3, 4/2 |
| 13 | Chords | Extended and altered | 6, m6, 6/9, maj9, 9, m9, 7♭9, 7♯9, 7♯11, maj7♯11, m11, 13 |

## Features

- A piano sound synthesized in the browser with the Web Audio API. No samples, no downloads.
- After each answer the notes light up on a keyboard, spelled correctly for the key or root.
- When you miss, play your answer and the right one back to back.
- A level is mastered at 18 of your last 20 correct. A "Most confused" list shows which pairs you mix up.
- Settings for chord playback (block, arpeggio or both), fixed or random key, cadence on or off, and auto-advance.
- Keyboard shortcuts: <kbd>Space</kbd> plays, <kbd>1</kbd>–<kbd>=</kbd> answer, <kbd>Enter</kbd> goes to the next question.

Progress is saved in your browser's local storage, so it stays on that device.

## Run it

It is a single HTML file with no build step. Open `index.html` in a browser, or serve the folder with any static host such as GitHub Pages.
